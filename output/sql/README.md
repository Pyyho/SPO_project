# SQL для практической работы 4

Скрипты рассчитаны на PostgreSQL 15 и новее. Они создают схему `trip_mgmt`, загружают демонстрационные данные и проверяют ключевые связи и ограничения.

Порядок выполнения:

```powershell
psql -v ON_ERROR_STOP=1 -d trip_db -f 001_schema.sql
psql -v ON_ERROR_STOP=1 -d trip_db -f 002_seed.sql
psql -v ON_ERROR_STOP=1 -d trip_db -f 003_verification.sql
```

Скрипт `004_access_control.sql` выполняется отдельно от имени владельца БД или администратора. В управляемом PostgreSQL роли входа обычно создаются средствами платформы, после чего им назначаются групповые роли `trip_app` и `trip_auditor`.

`002_seed.sql` очищает таблицы схемы и предназначен только для локальной разработки или демонстрационной базы. Хеши паролей в нём синтетические и не подходят для входа в приложение.
